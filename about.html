どう動くか how it works

1

時計をそろえる

サーバが唯一の時計。各端末は自分のズレを測って合わせる。LANで±1〜3ms、LTEで±10〜20ms、Piの箱の中なら±0.5ms。

2

音は先に配る

入口のQRで曲は先に届いている。本番の「鳴らせ」は「いつ」だけを配るので、5,000台でも帯域は増えない。

3

距離のぶん遅らせる

ステージから遠い端末ほど遅らせて、音の波面に乗せる。ゾーンの旗かGPSで自動。だから会場全体で位相がそろう。

画面 screens

FOHコンソール。上に「接続・鳴っている・準備OK・失敗」の一文。ショーの順番どおりに、進める → 鳴らす → 光らせる → ゾーン → 端末 → Pi箱 → 記録 → 設定。

既存のフェスにそのまま刺さる plugs into what you already run

卓の aux を1本入れるか、Dante/AES67 のストリームを受ける。照明卓から OSC で cue を打ち、タイムコードに乗せ、Art-Net/sACN で会場の灯体をスマホと同じ時計に乗せる。

持っているものつなぎ方
DanteDante Virtual Soundcard か AVIO USB で入力、または機器のAES67モードでマルチキャスト受信(--aes67・--sapで自動発見)
AES67 / Ravennaそのまま受信。チャンネル割当は --map
MADI / AVB / アナログ / USBオーディオインターフェース経由で --input。PA融合は80ms
QLab / grandMA / Eos / AbletonOSC で /soluna/cue /soluna/go /soluna/light。タイムコードは /soluna/tc か LTC 音声
会場の灯体Art-Net / sACN 出力。スマホと同じパターン・同じ時計で
プロジェクター / LEDウォール/screen を開いた MacBook + HDMI

Piは、電源を入れるだけ the SOLUNA box

勝手に集まる

箱同士が見つけ合い、1台がサーバ(時計の親)に。残りはスピーカー。設定はゼロ。

1台死んでも続く

10秒ごとにショーの控えを持ち合い、サーバが消えたら15〜20秒で別の箱が引き継ぐ。プロセスが落ちれば6秒で自己復旧。

繋ぐと画面が開く

箱のWi-Fi「SOLUNA」に入ると設定画面が自動で開く。パスワード無しでも、箱のWeb以外は遮断された閉じた網。

どのDACでも

USB、GPIOのI2S DAC、内蔵。刺せば自動で切り替わる。ゾーンの割当はFOH画面から。

使いどころ where it fits

●フェスの中後方の明瞭度。ディレイタワーの代わりに、客席15m格子のPiスピーカー+観客のスマホ
●サイレント/分散型のパーティー、屋外映画、光の演出をスマホの群れで
●企業イベント・展示。プロジェクターと来場者の端末を同じ時計に乗せる
●リビングで2台のスマホからでも、同じコードが動く
